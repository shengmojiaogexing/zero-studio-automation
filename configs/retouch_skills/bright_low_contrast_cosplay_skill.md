# Cosplay 亮调低反差修图工作流 (ACR + PS)

> 预设代码：`bright_low_contrast`（热加载 Skill，自动注入视觉仿色大脑与 PS MCP 编排器）
> 核心逻辑：**先统一压平反差定正白 → 分离主体与背景独立控制 → 局部恢复对比度与角色固有色 → AI 精修与质感收尾**。

## 适用场景
- 漫展场照（尤其是会展中心等逆光大光比、现场灯光偏绿/偏青蓝环境）
- 亮调低反差（通透、干净、白里透粉肤色）人像后期
- Camera Raw 与 Photoshop 分层非破坏性修图参数逻辑

---

## 第一阶段：Camera Raw (ACR) 底层影调与色彩统一
**核心目标**：把高反差原图“压平”成类似手机直出的低反差灰底，找回全部高光与暗部细节，并将白平衡校准至“正白”。

1. **套用基础配置文件（去反差）**
   - 在 ACR 配置文件中导入并套用相机对应的扁平/标准去反差配置文件（如 Nikon/Sony/Canon 对应机型的平淡预设，索尼 A7M3/A7R/A7C 系列需核对准确机型后缀）。
2. **光影反差压平（找回细节）**
   - 高光：降至 `-100` 左右（以背景高光细节恢复、人物边缘保留微弱高光轮廓为阈值）。
   - 阴影 / 黑色：拉至 `+80` 左右（根据服装暗部细节灵活微调；若暗部仍死黑可拉至 `+100`，若发灰丧失体积感则回调）。
   - 白色：适度提升以恢复通透亮度，同时微降曝光防止背景过曝。
3. **白平衡校准（定“正白”）**
   - 以画面中人物的纯白/纯黑衣物为参考基准，调节色温与色调，使其呈现不偏冷、不偏暖、不偏绿、不偏洋红的“正白/正黑”。
   - 机型微调参考：索尼/尼康新机型套配置文件后若微偏蓝绿，向暖色与洋红微调；松下偏洋红向绿微调；佳能自带红润倾向微调即可。
4. **自然饱和度与清晰度**
   - 自然饱和度：`+25` 至 `+27`（拉起暗淡细节色彩）。
   - 饱和度：小幅降低（压住高饱和杂色）。
   - 清晰度：保持 `0` 不动（避免画面变脏、皮肤显粗糙）。
5. **HSL 肤色与场馆偏色初调（微调原则：每次仅动 5%）**
   - **色相**：
     - 场馆环境绿/青偏色：绿色向黄/蓝微调，避免死绿。
     - 肤色校准（红/橙/黄）：人脸由红（腮红/唇）、橙（主肤色）、黄（顶光受光面）组成。皮肤发红向橙右移；发黄向橙左移；注意黄色会联动背景与金属饰品，幅度需克制。
     - 角色固有色（如紫发/紫衣、蓝衣）：保持不动，防止色相偏移。
   - **饱和度**：
     - 降橙色饱和度（使皮肤更白净）；降绿色饱和度（去除场馆环境杂色）；青色/蓝色降 `40~50`（保留底色，切忌拉到 `-100` 变成死灰）。
   - **明亮度**：
     - 提高橙色、黄色明亮度（提亮肤色，呈现白里透粉）；微提绿、青、蓝明亮度。
6. **细节降噪与光学矫正**
   - 使用 AI 去杂色（降噪）清理高感噪点。
   - 镜头校正：大广角镜头可开启扭曲度（畸变）校正，关闭暗角校正（保留自然边缘过渡）。
   - 去紫边：老镜头可微调去紫边/绿边，但若导致嘴唇、瞳孔或红色服装高光掉色，立即归零留到 PS 手动处理。
7. **校准面板底层微调**
   - 相机校准：三原色色相/饱和度参考微调（如红原色色相 `+13`、绿原色色相 `+13`、蓝原色色相 `+26` 附近，视肤色通透度微调），最后整体回看微调曝光与阴影后导入 PS。

## 第二阶段：Photoshop 分层精修与光影重塑
**核心目标**：主体与背景严格分离，压暗压灰杂乱背景突出人物，按角色原设还原固有色。

1. **主体抠像与背景去色压灰**
   - 复制背景层，使用选择主体（`ps_select_subject`）提取人物蒙版（检查发丝、飘带、披风边缘）。
   - 选区反向选中背景（`ps_modify_selection(invert=True)`），新建**色阶调整层**（`ps_add_levels_layer` + `ps_set_layer_blend_opacity(blend_mode="luminosity")` 只控黑白灰不偏色），收拢滑块压平背景反差。
   - 仅作用于背景：新建**自然饱和度调整层**（`ps_add_vibrance_layer(vibrance=-70)`）或**色相/饱和度调整层**分通道压制：
     - 红色：降饱和度 + 降明度（消除背景红牌子、路人红衣等最抢眼的视觉干扰）。
     - 黄色：降饱和度约 `-50`，微降明度（保留场馆暖调高光氛围，切忌抽成死灰）。
     - 绿色：大幅降饱和度（`-80` 至 `-100`）去除杂色；青/蓝适度降饱和并微提明度，保持空气感。
2. **主体肤色提亮（独立控制）**
   - 使用 `skinTones` 色彩范围蒙版（`ps_select_color_range` + 羽化）新建色阶/曝光调整层（混合模式设为**明度 `luminosity`**），仅提亮人物皮肤区域（避开头发与衣服），使肤色白净通透。
3. **还原角色固有色（死白/死黑校准）**
   - 对照角色官方立绘或二创设定图，校准纯白/纯黑服装与鞋履（去除场馆反光染青/染黄）。
   - **避坑**：米白/复古白材质、激光皮/炫彩反光面料、金属装饰物不可直接抽成死白，必须忠于角色原设质感。
4. **恢复主体立体感与背景压暗**
   - **主体反差**：剪贴蒙版（`ps_set_clipping_mask`）绑定至主体，新建曝光度调整层微调曝光与**灰度系数 Gamma**（增强暗部扎实度，防止发灰）。
   - **背景压暗**：选中背景选区，新建曝光/曲线调整层压暗背景（墙面或顶棚反光严重时可叠加压暗 1~2 层）。
5. **液化与穿帮去除（AI 精修避坑）**
   - 液化规范：大画笔微调轮廓；甩动飘逸头发或衣摆时推拉中段弧度，切忌只拉发梢或衣角；注意背景栏杆、地平线横竖直线不被拉歪。
   - **AI 局部去杂物避坑**：严禁框选整片地面一次性去除路人（否则会连同脚下真实投影与地面反光一并抹除导致人物悬浮）；仅局部框选单个路人、脚架、杂物箱分批消除。
   - 皮肤磨皮：仅用简短指令或轻度高低频，严格保留皮肤纹理与红润气色。
6. **光影氛围与双中性灰重塑**
   - **环境高光辉光**：在背景上方新建图层（`ps_add_ambient_glow_layer`，混合模式滤色/线性减淡，不透明度 `10%~30%`）增强空气通透感。
   - **双中性灰立体感**：新建 50% 中性灰图层（`ps_create_neutral_gray_layer`，柔光），强化五官与服装褶皱立体度。
   - **色彩点睛**：给主体新建自然饱和度（`ps_add_vibrance_layer(vibrance=15)` + 剪贴蒙版），微提主体色彩鲜活度。
7. **高反差保留质感锐化（收尾）**
   - 仅针对主体盖印可见图层（应用主体蒙版，不锐化背景以免放大背景噪点）。
   - 执行高反差保留（`ps_apply_high_pass_sharpen(radius=2.0, blend_mode="linearlight", opacity=30.0)`），半径 `2.0px`，混合模式**线性光**，不透明度 **`30%`** 完成出图。

## 常见误区与核心原则
- **修图是妥协的艺术**：所有参数（如阴影 `+80`、蓝色 `-50`）均为基准参考，必须根据现场光比与原图底色动态调整，不可死套固定数值。
- **主体永远高于背景**：背景处理的核心是降饱和、压明度、去抢眼色（尤其是红色），绝不能让背景抢走主体视觉重心。
- **还原优先于风格化**：Cosplay 后期一切色彩校正（偏米白、冷白、激光材质）均以角色立绘设定为第一依据。
